# Engineering Memory

An AI-powered engineering memory system that remembers
past incidents, failed approaches, successful fixes, and
lessons learned.

## Architecture

Incident
    ↓
RECALL
    ↓
Hindsight
    ↓
Relevant Engineering Memories
    ↓
Groq
    ↓
Recommendation

Resolved Incident
    ↓
RETAIN
    ↓
Hindsight
    ↓
Organizational Memory

## Requirements

- Python 3.13+
- Hindsight
- Groq API key
